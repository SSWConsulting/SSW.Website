## See what SophieBot can do

SophieBot can answer questions about the SSW website, Rules, Events, GitHub, SharePoint, CRM, and more.

### Generative answers

1. **Website** - type "Find the SSW webpage about AI development"
2. **Rules** - type "Give me some rules for prompt engineering"
3. **Events** - type "Upcoming SSW events"
4. **GitHub** - type "What's the GitHub URL for SSW Rules?"
5. **SharePoint** - type "Email template for working from home"
6. **CRM** - type "Employee responsibilities related to Tina"

### Custom queries

1. Type "Hi"
2. Type "Who is Adam Cogan?"
3. Type "Who works in Melbourne?"
4. Type "Who is in the Sydney office right now?"
5. Type "Who is working on TinaCMS?"
6. Type "Show all commands"

Enjoy with your own commands!
