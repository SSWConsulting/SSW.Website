# SSW SophieBot docs

## Make sure the private address is disabled

When you connect your device to SSW WIFI (or any Wi-Fi managed by a Unifi controller), make sure the private address is disabled.

If the private address is enabled, the controller assigns and records a different MAC address each time the device connects. That causes a mismatch in SophieBot's database between the employee's registered device and presence detection.
