# SSW SophieBot docs

## Make sure the private address is disabled

When you connect your device to SSW WIFI (or any Wi-Fi managed by a Unifi controller), make sure the private address is disabled.

If the private address is enabled, the controller records the randomized MAC address instead of the device's registered hardware address. That causes a mismatch in SophieBot's database between the employee's registered device and presence detection.
